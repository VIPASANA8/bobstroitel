# Poker Trainer v0.11 · Component UI

## Poker8 Online MVP

The network product is a Telegram Mini App with six public 6-max tables, virtual PLAY balances, authoritative server hands, reconnectable WebSockets, FIFO seating, chat, profile/history, and tenant branding. It has no deposits, withdrawals, KYC, USDT/TRC20, blockchain, or real-money API.

Local development:

```powershell
uv pip install -r requirements.txt
$env:POKER8_DATABASE_URL='sqlite+aiosqlite:///./data/poker8_online_dev.sqlite3'
$env:POKER8_COORDINATOR_ENABLED='1'
.venv\Scripts\python.exe -m alembic upgrade head
.venv\Scripts\uvicorn.exe app.production:app --reload
```

Production requires PostgreSQL, `POKER8_DEFAULT_BOT_TOKEN`, exact tenant host bindings, and Telegram `initData` authentication. Open `/` for the lobby, `/table?table=<id>` for the table, and `/static/profile.html` for the profile. The complete operational procedure is in `docs/runbooks/online-mvp.md`.

# Poker Trainer v0.9.2 RU — профили, сохранённые столы и bot-only режим

Локальный 2–7-max No-Limit Texas Hold'em тренажёр с долговременными профилями игроков, несколькими людьми за одним столом, до 6 ботами, сохранёнными составами и режимом наблюдения.

## Главное в v0.9

### Несколько людей за одним столом

Любое из 7 мест теперь может быть:

- человеком из сохранённых профилей;
- ботом;
- свободным местом.

Один профиль нельзя посадить дважды. В локальном режиме используется **hot-seat**: когда ход переходит к человеку, интерфейс показывает только его карты; карты других человеческих профилей остаются скрытыми до вскрытия.

Пример:

```text
Seat 1 — Лия
Seat 2 — Артём
Seat 3 — BOT / сложный
Seat 4 — Макс
Seat 5 — BOT / максимальный
Seat 6 — свободно
Seat 7 — BOT / нормальный
```

### Долговременные профили

У каждого человеческого профиля отдельно сохраняются:

- банкролл;
- история раздач;
- VPIP;
- PFR;
- 3-bet;
- Fold to 3-bet;
- постфлоп-агрессия;
- EV loss в доступных CFR-lite спотах;
- долговременная модель поведения.

### Сохранённые столы

Можно сохранить текущий состав под именем, например `Пятничный стол`, а потом открыть его снова. Сохраняются состав, боты, их сложности, текущие балансы и положение дилерской кнопки.

### Стол без людей

Разрешён **bot-only** стол на 2–6 ботов. Седьмой бот по-прежнему запрещён: на одном столе максимум 6 ботов.

В режиме наблюдения сервер выполняет по одному действию бота, чтобы браузер успевал показать:

- ставки;
- движение фишек;
- флоп / тёрн / ривер;
- вскрытие;
- выплату банка.

### Бесконечный режим

Кнопка `∞ Бесконечный` автоматически запускает следующую раздачу после завершения предыдущей. В bot-only режиме можно поставить наблюдение на паузу и продолжить позже.

## Что происходит, если бот проиграл весь депозит

**Мгновенного авторебая нет.**

Если у бота после раздачи осталось меньше 1 ББ:

1. бот покидает текущий рум;
2. его кресло сразу становится свободным;
3. это место может немедленно занять человек или другой бот;
4. сам проигравший бот уходит на cooldown;
5. cooldown выбирается в настройках комнаты: **5 / 10 / 15 минут**;
6. после тайм-аута бот получает новый депозит 1000 ББ;
7. он возвращается только если есть любое свободное место;
8. если его старое кресло уже занял человек, бот садится на другое свободное;
9. если свободных мест нет, бот продолжает ждать вне стола.

То есть тайм-аут принадлежит **боту, а не креслу**.

В боковой панели отображается список `БОТЫ ВНЕ СТОЛА` с обратным отсчётом.

## 7-max

Поддерживается 2–7 активных игроков и позиции:

```text
UTG → UTG+1 → HJ → CO → BTN → SB → BB
```

Есть:

- корректная очередность действий;
- multiway pot;
- main pot + side pots;
- несколько all-in;
- multiway showdown;
- автоматическое движение BTN / SB / BB.

## Визуал

Сохранены визуальные слои предыдущих версий:

- фишки банка и ставок;
- движение фишек;
- дилерская кнопка `D`;
- анимация раздачи карт;
- открытие flop / turn / river по фазам;
- переворот карт на showdown;
- статусы `ХОД / ПАС / ОЛЛ-ИН`;
- десятка показывается как **10**, а не `T`.

## Запуск на Windows

В папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

```powershell

.\.venv\Scripts\Activate.ps1
```

Открыть:

```text
http://127.0.0.1:8000
```

Swagger:

```text
http://127.0.0.1:8000/docs
```
