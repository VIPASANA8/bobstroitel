# Профиль Poker8: визуальная переработка

Цель: собрать имя, развитие, баланс и игровые результаты в один понятный экран, не меняя начисления XP, миссии, достижения или API.

## Что обнаружено на production

- «Раздачи / Раздач» и «Победы / Выиграно раздач» выглядят дублями, хотя `users` хранит весь срок жизни, а `progress_days` — новый период учёта. Сохраняем оба смысла: общий объём у имени; объём зачётной выборки рядом с результатом.
- Опыт вынесен в отдельную плитку от уровня. Баланс отделён от пополнения двенадцатью строками достижений.
- Пять равнозначных плиток в сетке из четырёх оставляют одинокую вторую строку на ПК.
- Двойные заголовки, английские служебные слова и длинный Telegram ID занимают место без пользы.
- Достижения повторяют одинаковые рамки; история раздач и журнал операций последовательно удлиняют страницу.
- Недоступное пополнение показывает целую отключённую форму.
- Вращающийся псевдоэлемент фона раздувает scrollWidth: измерено 3413px при viewport 390px.
- Последовательная загрузка и подавление ошибок создают пустые блоки; первый вход может вернуть auth payload без полей прогрессии.

## Решение

Сдержанная тёмная карточка игрока с монограммой, уровнем, XP и балансом. Фиолетовый акцент обозначает развитие; зелёный и красный сохраняют смысл результата. На ПК задания и статистика стоят рядом; на телефоне складываются. Уровень не рисует выдуманный процент: API сообщает общий XP и остаток, но не размер текущей ступени.

Достижения — сетка значков с шестью видимыми элементами и раскрытием остальных. Секретные названия не раскрываются до получения. История — одна секция с доступными с клавиатуры вкладками «Раздачи» и «Операции», пять последних строк с раскрытием до двадцати. Поля пополнения доступны только при разрешении сервера; якорь `#topup` сохраняется. Каждая секция загружается независимо и показывает собственную ошибку.

## Проверка результата

- Основной набор: `pytest --ignore=tests/e2e -q` — **726 passed, 3 skipped, 6 deselected**.
- Новый профиль: **10 браузерных проверок**. Начальный красный прогон подтвердил `LEVEL undefined` при первом входе; новая загрузка исправляет его.
- Регрессии стола: **14 passed** (`test_trainer_layer_retirement.py` и настольное расположение действий).
- После финальных правок: статические проверки профиля и новый браузерный набор — **19 passed**.
- Проверены 360/390/768/1280px, длинное имя, пустые данные, ошибки отдельных API, максимальный уровень, отрицательный результат, клавиатурные вкладки, замена, включённое и отключённое пополнение. Горизонтального переполнения нет.
- Независимое ревью: оба замечания устранены — пояснение статистики доступно на телефоне через details, metadata достижений видимы; для HTTP без crypto.randomUUID сохранён fallback. Повторное ревью не нашло блокирующих регрессий.
- Скриншоты реальной вёрстки с тестовыми данными: `.superpowers/profile-preview-desktop.png`, `.superpowers/profile-preview-mobile.png`. Локальный просмотр: http://127.0.0.1:8877/static/profile.html. Это изолированные демонстрационные данные, не production.
- Начисления, API и миграции не менялись. Дизайн лобби и столов сохранён; общие токены ресурсов обновлены для сброса кэша.
