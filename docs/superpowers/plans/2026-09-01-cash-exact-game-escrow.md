# CASH exact game and escrow — пакет 3

**Goal:** Дать будущему `CASH_USDT`-столу полностью целочисленный путь от бай-ина до расчёта и возврата стека, не открывая публичную денежную игру.

**Scope:** Точный режим общего poker engine, отдельные CASH-поля посадки, внутренний сервис escrow/settlement, миграция и PostgreSQL-тесты. Без депозитов, выводов, публичных CASH route, админ-бота и вкладок лобби.

## Task 1: Точные фишки движка

- [x] Добавить в общий `PokerEngine` режим целых фишек с настраиваемыми SB/BB; PLAY-поведение оставить совместимым.
- [x] В exact-режиме отвергать float на входе и сохранять int через serialize/deserialize.
- [x] Делить main/side pots целочисленно; нечётные фишки выдавать победителям по часовой стрелке от баттона.

## Task 2: Отдельная CASH-посадка

- [x] Добавить `cash_escrow_account_id` и `stack_micros`, не переиспользовать PLAY escrow/FK.
- [x] Бай-ин должен быть кратен номиналу 0.01 USDT, укладываться в 40–100 BB и одной транзакцией переводиться из available в уникальный escrow посадки.
- [x] На CASH-столе запрещены system seats; выход возвращает остаток из того же escrow ровно один раз.

## Task 3: Расчёт и восстановление

- [x] Зафиксировать CASH start/end/net в истории раздачи в micro-USDT.
- [x] Settlement сверяет сохранённые начальные стеки, seat stack и escrow; при расхождении ставит только этот стол на pause без faucet-доплаты.
- [x] Проводки settlement, terminal hand и seat stacks фиксируются одной транзакцией; повтор с тем же результатом ничего не меняет, другой результат отвергается.

## Task 4: Миграция и проверка

- [x] Добавить миграцию от `20260901_0015`, защищённый downgrade и новый ожидаемый head.
- [x] Проверить точные банки/остатки локально и escrow/settlement/restart на PostgreSQL.
- [x] Прогнать CASH и полную PLAY-регрессию, Alembic heads, compileall и diff check.

## Не является результатом

Этот пакет не включает внешний источник USDT и не включает CASH в HTTP/WebSocket/координаторе. Средства для тестов создаются только прямой mock-проводкой в изолированной PostgreSQL-схеме. Публичный `POKER8_CASH_MODE` остаётся `off`.
